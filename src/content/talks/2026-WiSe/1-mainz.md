A sumset-succinct representation of a point set X is given by sets A,B such that X=A+B={a+b∣a∈A, b∈B}. For a computational problem on X, we ask whether we can solve it faster when given such a sumset-succinct representation instead of the explicit set X. This setup arises naturally, for example, in dynamic programming algorithms where partial solutions need to be combined efficiently.

We discuss algorithmic and fine-grained complexity results for selected problems, with a focus on succinct skyline computation. In particular, we show that the output size plays a crucial role in both upper and lower running-time bounds, and leverage this output-sensitive perspective to design fast approximation algorithms.

This is joint work with Carina Truschel, Peter Sanders, Geri Gokaj and Marvin Künnemann.

Every *n*-vertex graph *G* defines an *n*-qubit quantum state |G⟩. A rich literature connects quantum computational properties of |G⟩ with purely combinatorial properties of *G*. We briefly overview some of these connections, then explain how a combinatorial property introduced by Campbell, Gollin, Hatzel, Kwon, McCarty, Oum, and Wiederrecht (SODA 2026) can be used to define the “*k*-entangled clusters” of |G⟩. We show that, for each fixed *k*, these clusters can be computed in polynomial time (by a classical algorithm).

This is joint work with Bourneuf, Claudet, Kim, Sullivan, and Thomassé.
